SYSTEM / ABOUT

ROITH System Profile

A digital forensics workspace designed around evidence handling, integrity and clear reporting.

ROITH / F

This release runs entirely in your browser. Active capabilities: SHA-256, basic file signature recognition, entropy estimate, printable string extraction, browser metadata timeline, local case notes, JSON manifests and PDF reports. It is not a replacement for Kali Linux or a certified forensic suite. Kali is a Linux distribution; ROITH is intended to become a specialized investigation workspace that can orchestrate selected tools safely.

Evidence selected here is processed locally. Case notes are stored in local browser storage. Do not use this prototype as the sole basis for legal or disciplinary conclusions.
