Capabilities and limitations / الإمكانات والحدود

This release performs real SHA-256 hashing, basic file signature identification, entropy estimation, printable ASCII extraction, a limited modified-time timeline, JSON manifests and PDF reports.

It does not yet run Kali, Autopsy, Volatility, Nmap, or parse disk images, EVTX, PCAP or memory dumps. A separate hardened Linux engine is required.

Educational triage utility, not a certified forensic acquisition suite. Validate findings with established forensic tools.
